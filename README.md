# 균열 원정대 (Riftbound Expedition)

중세, 현대, 우주의 시대가 어둠에 삼켜진 뒤 마지막 등불 아래 모인 21인의 영웅으로 등불을 지키는 3D 웹 자동전투 액션입니다. 브라우저에서 바로 실행됩니다 (three.js, 빌드 과정 없음).

## 현재 빌드 (첫 플레이 가능 버전)
- 영웅 21종 (남 11, 여 10), 파티 5인 편성, 엠버로 해금
- 시대 3종(중세, 현대, 우주) 시너지와 역할 조합 시너지
- 도로 전진 → 무리 3번 자동전투 → 스테이지 보스(오우거, 티렉스, 메카 순환) → 재점화와 강화 카드, 전리품 등급 5단계(낡은~유물)
- 전멸하면 불꽃 하나 소모 후 한 단계 후퇴(불꽃 3개), 0개면 원정 종료와 엠버 정산
- 적 7종: 쥐, 감염자, 해골 무법자, 용암 골렘, 보스 3종
- 수동(WASD, 모바일 조이스틱) 또는 위임(자동) 전환, Space

## 아직 없는 것 (전체 목표)
사운드, 영웅별 전용 이펙트, 무기 표시, 밸런스 조정, 실기기 터치 검증. (5개 구역, 3D 도감, 구역 클리어 해금은 구현됨, 구역 2~5 시각 검증과 25스테이지 흐름은 미검증)
